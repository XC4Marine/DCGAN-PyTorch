# WaveGAN Crest + PSD 联合损失实验报告

## 1. 实验目标

在不改变 WaveGAN-GP 网络结构的条件下，在生成器目标中联合加入 Crest 与全局 PSD 辅助损失：

```text
L_G = L_adv + lambda_crest * L_crest + lambda_psd * L_psd
```

- `L_crest`：复用 `wavegan_crest/CrestFactorLoss`，约束逐波形峰值与 crest factor。
- `L_psd`：复用 `wavegan_PSDLoss/GlobalSpectralLoss`，约束真实与生成 batch 的平均 log-PSD。

训练使用 `D:\Project_Github\DCGAN-PyTorch\data\wav`，WaveGAN-GP 的 batch size 为 64、训练 200 epochs、seed 为 369/370/371。评估使用固定 latent seed `369`，所有模型采用相同数量的生成样本。

## 2. 搜索与对照

联合权重先在 Crest=`0.1, 0.3, 0.5, 0.7, 1.0` 和 PSD=`0.1, 0.2, 0.4, 0.7, 1.0` 上完成 25 组粗搜索；随后围绕粗搜索第一名完成 3×3 局部细化。前三个组合使用 seed `369, 370, 371` 复验，共完成 39 个联合模型 checkpoint。

对照模型按各自辅助损失的直接目标选择：

- 原始 WaveGAN：epoch 200 checkpoint。
- Crest-only：`lambda_crest=1.0`，其峰值距离最低。
- PSD-only：`lambda_psd=0.4`，其 log-PSD 误差最低。

## 3. 当前评分口径

当前综合分不使用峰值位置、绝对 PSD、谱质心和双向 NN-L2。保留的指标均为“越低越好”的误差或距离：

- 时域组：峰值距离、峰峰值距离、RMS 距离、FWHM 距离。
- 频域组：log-PSD 误差、主频距离、谱带宽距离、-3 dB 带宽距离。

单指标相对原始 WaveGAN 的分数为：

```text
s_i = log(metric_model / metric_wavegan)
```

时域组和频域组内分别取均值，两个组再等权平均。负数表示该模型的误差低于原始 WaveGAN。

### -3 dB 带宽距离

对每条 128 点波形计算单边功率谱，排除 DC 后找到最大功率频点。以该峰为中心，统计功率不低于峰值一半的连续频率区间宽度，作为该波形的 -3 dB 带宽。真实集和生成集的 -3 dB 带宽分布采用一维 Wasserstein 距离比较，单位为 Hz。

## 4. 最优联合权重

在三种子复验组合中，最佳联合权重为：

```text
lambda_crest = 0.6
lambda_psd   = 0.15
```

| 联合权重 | 时域分 | 频域分 | 综合分 |
| --- | ---: | ---: | ---: |
| Crest 0.6 / PSD 0.15 | -0.4190 | -0.6150 | **-0.5170 ± 0.0600** |
| Crest 1.0 / PSD 0.1 | **-0.5954** | -0.4237 | -0.5095 ± 0.0199 |
| Crest 0.7 / PSD 0.1 | -0.4178 | -0.4369 | -0.4274 ± 0.0893 |
