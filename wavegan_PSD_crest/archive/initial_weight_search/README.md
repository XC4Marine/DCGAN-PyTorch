# 初始权重搜索历史归档

此目录只保存初始分阶段权重搜索的历史证据，不是当前正式结果入口。

保留内容：

- `EXPERIMENT_REPORT.md`：初始搜索完成时的报告快照。
- `refresh_minus_3db_metrics.py`：加入 -3 dB 带宽指标时使用的一次性刷新脚本快照；移动后不作为现行入口执行。
- `logs/`：初始搜索、恢复运行和 -3 dB 指标刷新的总控标准输出/错误输出。

初始搜索的逐组结果仍位于项目根目录的 `runs/`、`controls/`、`results/`、`images/` 和 `checkpoints/`。当前十五种子正式结论见 `voyage_split_full/results/EXPERIMENT_REPORT.md`。
