# WaveGAN 希尔伯特包络损失：batch size 实验结论

## 结论

在本轮固定 200 epochs、训练 seed 369、Hilbert 损失权重 1 的航次互斥实验中，希尔伯特包络损失使四种 batch size 的**逐样本包络误差**全部下降，综合分也全部小幅下降。但它没有稳定改善时域波形：batch 16、64、128 的时域综合分反而变差，两个方向的 NN-L2 也未在所有组同步改善。因此，本轮证据支持“包络拟合改善、综合质量略有改善”，不支持“原始波形各方面普遍改善”。

若按预设的时域与频域等权综合分选本轮设置，**batch size 16 最合适**：Hilbert 组综合分 -0.10370，四个 Hilbert 组中最低；相同 batch 的 Raw 为 -0.09266，配对改善 -0.01104。batch 32 可以作为更少训练更新的候选：它的时域分和两个方向的 NN-L2 都优于同 batch Raw，但频域分变差，最终综合改善仅 -0.00433。

## 数据对照

综合分统一相对本轮 Raw batch 64；配对变化相对相同 batch size 的 Raw，越低越好。包络误差变化指逐样本相对整个真实测试集平均包络的 MSE，相同 batch 内相对变化。

| Batch size | Raw 综合分 | Hilbert 综合分 | 配对综合变化 | 配对时域变化 | 配对频域变化 | 逐样本包络 MSE 变化 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 16 | -0.09266 | **-0.10370** | -0.01104 | +0.04200 | -0.06408 | -2.47% |
| 32 | -0.06624 | -0.07057 | -0.00433 | **-0.11149** | +0.10283 | **-8.16%** |
| 64 | 0.00000 | -0.00784 | -0.00784 | +0.06498 | -0.08065 | -1.88% |
| 128 | +0.21959 | +0.19852 | -0.02107 | +0.00503 | -0.04717 | -6.64% |

负的配对综合变化表示优于同 batch 的 Raw；表中的综合分为对数误差比值，不是百分比。虽然 batch 128 相对自己的 Raw 改善最大，其绝对综合分仍最差。

batch 16 的平均包络 MSE 从 0.001061 降至 0.000861，下降 18.86%；log-PSD 误差下降 1.02%，-3 dB 带宽误差下降 11.13%。与此同时，峰峰值分布距离上升 14.92%，生成→真实 NN-L2 从 1.43958 增至 1.44990，真实→生成 NN-L2 从 1.27560 降至 1.26011。因此 batch 16 的增益主要体现在包络与频域，时域证据并不一致。包络对比图显示平均形状接近，但部分生成样本峰值高于测试集平均包络；该图不能单独证明波形质量提升。

batch 32 的逐样本包络 MSE 下降 8.16%，两个 NN-L2 分别下降 2.21% 和 2.24%，RMS 与 FWHM 距离也下降；-3 dB 带宽误差则上升 25.37%。batch 64 的两个 NN-L2 均上升；batch 128 的平均包络 MSE 上升 6.08%，其生成包络逐点标准差均值由 0.08940 降至 0.08226，低于真实测试集的 0.09227。仅凭逐样本包络 MSE 更低，不能把 batch 128 判为最佳。

## 解释范围

八组均完成 200 epochs，并保留第 50、100、150、200 轮 checkpoint。训练集 14,734 条、测试集 3,684 条，测试航次为 Voyage_Ori_02、Voyage_Ori_08、Voyage_Ori_15。

固定 epoch 数时，batch 16/32/64/128 各自的生成器更新数为 36,800/18,400/9,200/4,600。因此 batch 16 的领先反映当前训练预算下的结果，不能单独归因于较小 batch 对包络目标更有利。本轮只有一个训练种子；也用同一测试集挑选 batch size。若要把 batch 16 作为稳定的最终配置，需要在更多训练种子及独立验证设置下复核。
